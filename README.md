# 荒野回响 · Wild Echoes

纯 HTML、CSS 与原生 JavaScript Canvas 实现的无尽割草生存游戏，无运行时第三方依赖。

- 自动瞄准与发射；WASD / 方向键移动，空格释放天雷轰击，Esc / P 暂停。
- 手机拖动战斗区域使用虚拟摇杆，右下角按钮释放天雷轰击。
- 开局可直接选择三位独立形象的角色：游侠使用绿兜帽与弓箭，初始疾风连射 1 级、移动速度约提高 8%；守林人穿木甲与厚斗篷，初始环刃 1 级、生命提高 25%、移动速度降低约 8%；唤雷者穿蓝紫长袍并持雷杖，初始唤雷 1 级、主动天雷冷却缩短至 12 秒、生命降低 15%。所有角色保留基础飞矢，可在局内发展全部流派。
- 拾取灵晶获得经验，每次升级从三个随机强化中选择一个；拉开成长间隔，连续获得的升级在同一面板完成选择，经验完整保留。
- 环绕飞刃、范围冲击波、连锁闪电与多项被动强化。
- 环刃施加持续 2 秒的流血，重复命中刷新时长、不叠层；大地回响或进化回波命中流血目标时消耗状态，本次伤害提高 25%。唤雷和主动天雷施加 2.5 秒感电，下次飞矢或环刃命中会向附近另一名敌人传导一次；传导与流血不会递归触发联动。
- 三种副武器升至 5 级自动进化：裂风环刃周期向外扩张，双重回响在原释放位置追加回波，雷暴链最多追击 5 个不同目标。进化沿用已有升级，不额外消耗经验或弹出选择。
- 副武器位初始 1 个，角色 5 / 8 级分别开放第 2 / 3 个；守林人和唤雷者的初始副武器占用已有位置。角色 2 / 5 / 8 级时有空位会优先提供新武器选项。分裂箭保留全伤主箭，副箭为 60% 伤害。
- 基础灵弹伤害 32，基础经验吸附范围 105；普通怪加快接近，自动索敌限定可见范围，减少远处清怪后的拾取空档。
- 主动技能天雷轰击：伤害覆盖释放时屏幕内的全部怪物，默认冷却 15 秒（唤雷者 12 秒），伤害随强化提升。
- 天雷采用蓝白分叉闪电、短促回闪与落点电弧；几何按次缓存，密集怪群中限制详细主雷数量，所有命中目标保留落点反馈。
- 森林光束与光斑固定在地图坐标上，随镜头移动，不跟随角色。
- 大树树干、巨石与倒木会阻挡主角、小怪和领主；沿边滑动，怪物会绕行。地形位置固定，出生点与道路留有通行空间。
- 地图稀疏分布泥地和爆炸蘑菇。泥地令敌我主动移动速度降至 74%，不会叠加减速；蘑菇被玩家武器击中后预警 0.9 秒，在半径 82 内爆炸，伤害敌人也会伤害主角，并能延迟引爆附近蘑菇。蘑菇本身不提供经验，击杀怪物照常掉落灵晶；出生区域留有安全空间。
- 地形与人物按脚底位置排列前后遮挡；树冠遮住主角时会淡化。障碍阻挡移动与敌方孢子弹，玩家灵弹、天雷与灵晶吸引仍可穿过。
- 冲锋野猪先锁定方向蓄力，再直线冲刺；撞上大树、巨石或倒木会短暂眩晕。孢子怪保持距离蓄力发射慢弹。
- 地图上会出现精英守卫宝箱，按方向指引前往挑战；击败守卫后靠近自动开启。可破坏的补给木箱提供沿路探索目标。
- 随机出现追逐宝物精和限时狩猎事件，可自由参加或忽略；狩猎需在标记区域内击杀普通怪物，宝物精会绕障逃跑。完成后掉落即时补给，不额外赠送经验；事件避开领主登场时段。
- 药草恢复 25 点生命，满血时留在地上；磁铁扩大经验吸附，狂暴提高 35% 伤害与 20% 灵弹发射频率，两种增益持续 8 秒，重复拾取刷新时长。道具直接生效，临时增益显示倒计时，不增加奖励选择弹窗。
- 主角、小怪与领主共用朝向一致的地面投影；阴影合并后统一透明绘制，重叠不累积变黑，角色按脚底位置排列前后遮挡。
- 没有时长上限；每分钟提升怪潮强度，常态刷怪之间穿插短促围攻与缓和，界面显示当前战斗阶段。
- 首位领主 02:00 出现，之后约每 150 秒迎来更强的领主；荒野领主与孢冠领主交替登场。前者蓄力震地，后者发射有预警的扇形孢子弹和三处固定孢爆，移动躲避或利用地形掩护。
- 同时最多一位领主存活，未击败时下一位会等待；后期升级仍可继续强化。
- 标准 / 轻松难度通过单选按钮切换，无尽模式本机纪录与可关闭的合成音效。

## 文件

- `dist/index.html`：页面、状态面板与弹窗。
- `dist/style.css`：桌面、手机竖屏与横屏布局。
- `dist/app.js`：Canvas 绘制、输入、音效与界面同步。
- `dist/engine.js`：独立战斗与升级逻辑。
- `dist/terrain.js`：固定地形、碰撞检测与绕行几何。
- `dist/adventure.js`：精英宝箱、补给木箱与即时道具。
- `dist/encounters.js`：限时狩猎与宝物精事件。
- `dist/bosses.js`：孢冠领主的攻击与预警状态。
- `dist/heroes.js`：三位角色的初始装备与属性。
- `dist/combat-status.js`：流血、感电与武器联动。
- `dist/environment.js`：稳定分布的泥地、蘑菇与延迟爆炸。

将 `dist` 作为静态网站目录即可部署，所有资源均使用相对路径。

## 版本号

开始画面的版本为 `v0.0.N`，`N` 是 GitHub 仓库 `goodleap/wild-reaper` 当前提交可达的历史提交总数，首次提交为 `v0.0.1`。GitHub Pages 在每次 `main` 推送后拉取完整历史并运行 `npm run stamp-version`，直接更新部署产物，不产生额外的版本提交；仅修改文档的提交也计入。

Sites 使用独立的源码仓库。每次同步发布前，先核对 GitHub `main` 的完整提交数，将即将提交的本次改动计入，再运行 `npm run stamp-version -- --commit-count N`，使 Sites 和 GitHub Pages 版本一致。请勿使用 Sites 自身的 Git 计数。版本仅增加最后一段，`v0.0.9` 之后是 `v0.0.10`。

## 验证

运行 `npm run check` 检查语法，`npm test` 运行整局模拟，以及暂停升级、全屏雷击及冷却、死亡、无尽进阶、地形碰撞与怪物绕行、围攻周期、屏外出生与索敌、经验守恒、领主预警、新怪攻击与地图奖励检查。`qa-expansion.mjs` 覆盖武器自动进化、原位回波、事件有效击杀与清理，以及孢冠领主的锁定预警、弹体上限和同帧击杀取消。

`qa-roles.mjs` 覆盖角色初始属性与装备、流血及感电的实际武器触发、无递归奖励、泥地移动、蘑菇延迟连锁、暂停冻结、重访及实体数量边界。

上一轮数值调整的五分钟同脚本对照：普通模式混合构筑从 34 次升级降至 12 次，升级间隔中位数从 9.6 秒变为 26.4 秒；箭矢、法术、混合构筑及轻松模式的样本为 10–12 次选择，首次约 9–13 秒。脚本会追踪经验、绕障碍和躲避近身威胁；部分样本启用无敌，仅用于检查成长，不能代替真人难度测试。经验按拾取与等级计算，没有强制定时升级。

上一轮宝箱内容扩展使用会探索宝箱、收集补给并躲避新攻击的脚本，对照扩展前后各三个五分钟样本（普通混合、手机箭矢、轻松混合，均未启用无敌）：升级次数保持 12 / 12 / 10 次，升级间隔中位数约 25–28 秒，均完成三次宝箱挑战。宝箱不额外赠送经验，磁铁只吸引已有灵晶；这些样本用于排查节奏突变，不代表真人难度结论。

已运行引擎模拟和 Canvas 离线绘制检查，包括地形稳定性与碰撞、五类怪物绕行、树冠淡化、阴影重叠不加深、脚底排序、雷电稀疏与密集场景、减少动态模式、DPR 与屏幕旋转；未进行真实浏览器与真实触屏设备测试。

武器进化与随机事件版本的三组五分钟正常生命值模拟分别有 12 / 12 / 11 次升级，中位间隔约 24–29 秒，完成 2–3 个事件。另一个优先强化已有副武器的七分钟样本正常触发环刃进化。十二分钟无敌模拟通过新旧领主轮换和实体数量上限检查；无敌样本只验证长期稳定性。

三英雄与互动环境版本分别运行三位角色的标准难度五分钟样本，以及一个手机视野唤雷者样本，均使用正常生命值。四组均升级 12 次，中位间隔约 26–29 秒，首次升级约 9–12 秒，未出现连续短间隔升级；蘑菇在每组中正常触发 6–11 次。脚本用于比较成长节奏与功能稳定性，不能替代真人操作和难度反馈。
