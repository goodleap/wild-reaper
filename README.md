# 荒野回响 · Wild Echoes

纯 HTML、CSS 与原生 JavaScript Canvas 实现的无尽割草生存游戏，无运行时第三方依赖。所有人物、建筑、地形与特效均由代码绘制。

## 操作与基础玩法

- 自动瞄准、自动攻击；WASD / 方向键移动，空格释放主动技能「天雷轰击」，触碰入口或宝箱自动互动，Esc / P 暂停。
- 手机拖动战斗区域使用虚拟摇杆，通过屏幕按钮释放主动技能；移动触碰入口即可探索建筑或穿越传送门，接触商人打开货摊后手动购买。
- 开局固定使用旅人：米白软兜帽、绿色短披风、空手，速度 220、生命 100（轻松模式 140），初始仅有翠羽飞矢。标准 / 轻松难度使用单选按钮，保存本机纪录和难度偏好，可关闭合成音效。
- 没有时长上限；荒野怪潮随时间升级，穿插短促围攻与缓和。区域首领固定驻守封印的传送门，走近才交战；击败后立即选择区域超级技能，并激活可反复往返的传送门。

链接添加 `?debug`、`?debug=1` 或 `?debug=true` 可进入调试模式，开始页版本旁显示 DEBUG。首区域的城堡入口会放在出生点附近，便于走过去测试进出、迷宫和宝藏；普通模式按正常探索距离生成。出生点外围会围上一圈普通怪物，目标 40 只，实际数量随安全地形调整，距出生点 220–305；为城堡保留通路，并避开障碍与危险地面，用于观察天使的高频守护。怪物保留正常属性和奖励，每局只生成一次。每局开场一次性获得 500 金币和 150 灵晶，灵晶按正常规则提供两次技能强化选择；进出城堡或切换区域不会再次发放。主动天雷冷却为 0，便于重复测试；角色等级与其他技能仍按正常规则运行。后续区域使用正常布局；去掉参数或设为 `debug=0` 即可关闭。

## 战斗节奏

开场先探索与收集灵晶，约 20 秒后预警第一波定向怪潮。3 秒方向提示后，从同一侧投放有限怪群；推进、蝙蝠掠袭与冲锋夹击轮换，野猪和孢子仍受出场时间与数量限制。界面显示剩余怪数。清完后获得少量灵晶，并吸引附近战利品；随后 8 秒停止新刷怪，再留出探索时间。拖得过久会进入较短缓和期，没有清潮奖励。怪物总数仍受上限约束，后期也保留明确的缓和阶段。

忽略远处遗迹、离开小屋战斗或保留已激活传送门，不会无限期压住其他事件。附近正在进行的可选战斗仍会避让；只有实际交战的驻门首领会限制新挑战，远处休眠首领不会阻塞探索。

城堡保留 5×5 连通迷宫与支路宝箱，首领主线缩短至约 8 个房间距离。主线战斗房集中安排 4–6 个守卫，清房提供少量灵晶，部分房间有药草；小地图记录已探索的墙体与地标，不提前指向隐藏首领。撤退保留守卫、清房和宝箱状态，不能重复刷取奖励。

## 随机事件与遗迹事件

遗迹是固定的高级探索目标，建筑在未开启、战斗中和完成后都留在原地。触碰实际入口启动；驻门首领则在走近时迎战。完成奖励每处仅一次，离开区域再返回不会重置。

## 画面与战斗表现

森林地表使用固定世界坐标的草叶、落叶、苔藓与泥土纹理；沼泽增加湿土、水洼、芦苇与枯木，遗迹增加磨损石板、碎石和断柱。城堡外观使用有厚度的石墙、拱门与塔楼，迷宫内使用铺石地面和立体墙体。树皮、岩面、倒木、小屋和这些区域素材都在首次使用时绘制为离屏位图并复用。小屋保持略大于主角的比例。树木具有宽冠、瘦高、偏冠、幼树和老树五类轮廓，石头具有圆钝、扁平、尖角、裂石和组合石堆五类轮廓；形状与尺寸使用独立的固定种子。碰撞、树冠淡化范围和日光投影随尺寸调整，障碍之间保留可通行的空隙。

林间狩猎以圆形石铺擂台标记有效战斗范围，加入磨损石沿、苔藓、中央纹章、入口踏步与四座矮火盆。击杀专属守卫逐步点亮边缘刻石；矮火盆与人物按脚底排序，并沿用合并阴影。擂台避开树石与水潭，完成后保留在地图上。

全部六类小怪和两类首领增加材质、明暗和轮廓细节：史莱姆的湿润表面、蝙蝠翼膜、甲虫背甲、蘑菇菌褶、野猪鬃毛，以及古树领主的树皮／枝角和孢冠领主的层叠菌盖。有限数量的姿态与受击帧共用缓存。甲虫使用横向侧视轮廓，隆起背甲下面露出侧腹，三条近侧腿与三条远侧腿交替爬行。按实际位移选择三种步态，左右转身；上下移动保留侧身，静止、被挡住和休眠时停步。转向后明暗仍对应世界右上方，全部侧视姿态缓存约 0.66 MB，与其他怪物共用 6 MB 总预算。补给木箱、普通宝箱、王城宝藏、传送门、拾取道具、敌方弹体与环刃也使用更完整的造型。

飞矢拥有箭镞、尾羽与渐细拖尾；连锁雷电具备分叉电弧、明亮核心与命中电花；地震呈现裂隙、石块和扬尘，主角与伙伴共用同一表现。怪物受击时短暂压缩、后仰，死亡时碎散消退；这些变化只影响画面，不改变攻击伤害、目标、冷却或奖励。

六种超级技能各有独立表现：荆棘生长、侵蚀雾团、带符文的能量射线、星陨的蓄能标记与坠落冲击、王庭灵剑，以及带卷吸碎屑的虚空漩涡。星陨在伤害触发前下降，命中后呈现焦痕和碎石；攻击原点、范围、伤害时刻与数值沿用现有规则。

素材均由项目代码生成，没有外部图片请求或新增运行依赖。森林、区域、水域、怪物、超级技能和道具位图分别采用 12、10、8、6、4、3 MiB 的缓存上限，并按需要创建素材。特效几何按对象缓存，时间来自战斗模拟，暂停时保持静止。普通特效总量上限 200，死亡效果上限 24；窄屏或密集战斗减少分叉与碎片，减少动态效果模式禁用拖尾运动、碎片飞散和镜头震动。攻击范围提示与敌人预警保持可见。

池塘和沼泽共用圆润、长条、肾形、双湾和分叉轮廓，具有 0.65、1、1.6、2.5、3.6 倍五档尺寸；大型沼泽可有干岛。岸线绘制、脚底下沉、地面减速与建筑避让共用同一套形状边界，飞行单位仍不受涉水影响。相邻水域保留干地间隙，建筑、出生点、营救点和传送门区域预留干地。水域生成按树根、石头和完整倒木的落地范围避让，岸边可相邻但不可互相穿插；通过固定候选位置重试保留大水域尺寸，回访不会挪动地形。水域按完整边界预载和保留，返回时尺寸、位置和轮廓保持稳定。水面按可见分块缓存，岸边芦苇、石子和纹理保持世界尺寸。

## 三种成长资源

| 资源 | 获得方式 | 用途 |
|---|---|---|
| 经验 | 击杀有经验的敌人后自动获得，无需拾取 | 自动提升角色等级；每级增加 2 点最大生命，并恢复相应的 2 点生命，基础伤害倍率增加 1 个百分点 |
| 灵晶 | 击杀非首领敌人掉落，靠近吸收；也可由探索奖励直接获得 | 独立累积至门槛后，暂停并从三项技能或被动强化中选择一项 |
| 金币 | 普通敌人有 8% 概率掉落 1 枚；特殊精英保底掉落 3 枚；探索奖励也可获得 | 向商人购买补给与遗物 |

角色升级不弹出选择面板，不提高移速或攻速，也不限制技能槽位。第一次灵晶强化固定在环刃、大地回响、唤雷中选择一种，选定后立即投入自动攻击；后续恢复常规强化池，灵晶费用保持不变。角色经验、灵晶强化进度与金币分别显示；灵晶和金币沿用靠近吸附，基础拾取范围 105。

灵晶强化需求随独立的强化次数递增，多余灵晶保留；一次攻击完成后才打开强化面板，避免中断同一批伤害。升级选项在面板内保持稳定，连续强化可在同一面板完成。召唤仆从不提供经验、灵晶或金币。营救与占据屋的有限守卫提供少量击杀经验及对应灵晶，事件完成本身不额外赠送角色经验。

灵晶仍使用混合三选一。卡片明确标识「技能 · 新获得 / 升级 / 分支 / 进化」和「属性 · 加强」，保留品质、名称与技能等级，将效果和关键数值合成一句：技能显示获得机制或升级变化，属性显示增量或范围变化；疾风连射、分裂箭标为飞矢专属强化。手机使用紧凑纵向卡片，去掉逐项数值表和重复说明；极小屏幕仍可整体滚动。普通、精良、稀有、史诗、传说使用独立品质标签与边框色，类型则用文字和图标区分；品质展示不改变原有奖励池和抽取概率。数值比较使用基础伤害，不包含临时狂暴或低生命遗物倍率。

## 常规技能与分支

| 技能 | 效果 | 进化或分支 |
|---|---|---|
| 翠羽飞矢 | 自动瞄准可见敌人，基础伤害 32 | 飞矢等级达到 4 后选择穿林飞矢或弹射飞矢；等级为 `1 + 疾风连射等级 + 分裂箭等级` |
| 环刃 | 绕身攻击，施加流血 | 5 级自动进化为周期扩张、收拢的裂风环刃 |
| 大地回响 | 环形震波、击退敌人 | 从 4 级升至 5 级时，选择连续震波或撼地重震 |
| 唤雷 | 自动连锁闪电，附加感电 | 从 4 级升至 5 级时，选择雷暴链或聚雷轰击 |
| 天雷轰击 | 手动释放，攻击当前屏幕内的敌人，基础冷却 15 秒 | 暂无分支 |

- 穿林飞矢最多穿透三个不同目标；弹射飞矢在附近可见敌人间最多跳转两次，每次后续命中保留上一段 65% 伤害。分裂箭保留全伤主箭，副箭造成 60% 伤害。
- 连续震波在施法原位置追加 60% 伤害的扩大回波；撼地重震扩大范围、增强击退并短暂减速普通敌人。雷暴链攻击最多五个目标，最后两段伤害降低；聚雷轰击集中攻击一个目标，优先首领与高生命敌人。
- 分支面板提供同一武器的两条路线和一项普通强化，可选普通强化暂缓。分支消耗一次灵晶强化机会，选定后本局固定，跨区域与城堡保留。
- 环刃施加持续 2 秒的流血，重复命中刷新时长、不叠层；地震与回震消耗流血，使该次伤害增加 25%。雷电与天雷施加 2.5 秒感电，下次飞矢或环刃命中时向附近另一名敌人传导一次。流血与传导不会递归触发联动。
- 被动强化包括锋芒、疾风连射、分裂箭、轻盈步伐、林间引力、古树之心与生生不息；后期仍有无尽强化选项。

## 伙伴与地图 NPC

触碰囚牢大门开启挑战，九名强化守卫在门外安全距离出现，预警 0.8 秒后才行动和造成伤害。侧面与背面有实体墙，门前通路留空；击败全部守卫后大门先打开，再走入囚牢靠近受困者，解救唤雷者或守林人。每次解救使「援助之力」增加一级，即基础伤害倍率增加 8 个百分点；奖励仅一次，本局持续有效。伙伴跟随助战 60 秒，不承受伤害、不挡路。挑战无倒计时，离开保留守卫生命与完成进度，解救后囚牢建筑仍在。

伙伴使用主角被动技能的高级版本，独立施法、独立冷却：唤雷者从自身位置发出最多五目标的连锁闪电，使用同样的闪电表现并附加感电；守林人从脚下发出地震和原位回震，可消耗流血。伙伴不使用主角的主动天雷表现。

两位伙伴与旅人的身高、身宽相近，靠服装、配色和装备细节区分。三者共用按实际位移推进的迈步与起伏，站定或被障碍挡住时停止迈步；跟随有起步与减速，减少原地微调。商人与天使也保持相近的人物比例。主角恢复早期版本的米白软兜帽、绿色短披风、围巾和空手造型，帽内暗色面部配两点浅色眼睛；保留按实际位移迈步及眨眼、受击、施法表情。NPC 通过衣褶、皮革、护甲及羽片明暗加强体积感。唤雷者使用微弯尖帽、斜持法杖和屈肘姿态，施法时轻抬法杖。静态部件按屏幕精度与朝向缓存，全部角色在双倍精度下不足 1.6 MB，预算为 2 MB；左右转身不会翻转世界光向。脸部仍只有两只简单眼睛：平时偶尔眨眼，真实扣血时挤眼 0.24 秒，施法时短暂专注，伙伴获救时短暂舒展；升级或入场无敌不会触发受伤表情。

- **商人**：独立站在荒野中的游商，与小屋分开生成，没有房屋或建筑碰撞。接触商人打开货摊，交易期间暂停战斗；成功购买一件商品后游商离开，交易面板关闭，本区域不再出现。仅查看、取消或购买失败时仍会留下。药剂 12 金币，恢复 35 点生命；磁引符与狂暴药剂各 8 金币；守护符 16 金币，可抵消下一次受击的至多 18 点伤害；一件固定的轮换遗物 60 金币。每样库存一份，金币不足、满血买药、已拥有遗物或护盾已充盈时不扣费。
- **天使**：固定驻守初始出生点与已激活传送门附近，封印中的门没有天使。治疗与攻击统一使用 150 守护半径，范围内主角每秒恢复最大生命的 3%，满血不溢出；无需按键。每 0.2 秒对守护范围内怪物降下半径 60 的天雷，基础伤害 115，随深入区域增加。光环由矢量路径生成符合屏幕精度的静态缓存，所有天使共用，最大约 1.6 MB；脚底小环单独绘制，不随守护半径放大。雷击复用主角的分叉与亮度算法，以金白色长雷从屏幕上方落至目标；单次显现 0.18 秒，每位天使同时最多一条长雷，不叠加全屏闪光。雷形在施放时缓存，镜头移动不会重生成闪烁的路径。天使不跟随玩家、不因提供治疗而消失。
- **小屋**：屋身略高于主角，屋檐宽约 66–70，地基宽 54–58、深 28–30；碰撞与阴影同步缩小。触碰屋门切换到约一屏的 400×400 木屋室内，有木地板、家具和屋内宝箱。普通小屋提供少量资源与药草；被占据小屋的四名守卫位于室内，与进入落点保持安全距离，清理后触碰屋内宝箱领取更好的宝藏。触碰出口回到荒野，重返保留守卫生命、击杀与开箱状态。

各区域配置游商、小屋、古堡、遗迹与传送门，天使随出生点或已激活的门固定安置。实体建筑有脚底碰撞与前后遮挡，屋顶遮住人物时淡化；入口留有通行空间，与危险机关和其他目标分开。已领取奖励不会因离开视野或区域往返而刷新。

## 区域、城堡与超级技能

区域按低语之森 → 迷雾沼泽 → 失落遗迹循环。每片新区域预先有封印传送门及驻守首领；走近交战，远离后首领返回驻地，已造成的伤害保留。击败首领当场打开区域超级技能选择，门同时激活；无需先找门领奖。之后触碰激活的门即可往返已到访区域。正在与区域首领交战时暂不能进入建筑或其他门。触碰交互使用较小接触范围，落点避开入口；持续站在同一入口不会重复开启，需先离开再进入。城堡、小屋与传送门的实际操作共用约 0.4 秒过渡：旧场景淡出 0.15 秒，全暗时切换一次，再淡入 0.25 秒。过渡冻结战斗、移动、冷却、增益与计时；切换前后清除残留键盘及触屏输入，持续按住的按键需松开重按。暂停和帮助会暂停过渡，恢复后继续；商店、开箱和奖励选择仍按原有方式即时打开。

城堡入口通向独立的 **5 × 5 有限迷宫**，含宽走廊、探索迷雾、有限守卫、三个支路宝箱与最终首领。迷宫由固定种子生成并保持连通，最终首领位于距入口最远的房间之一；城墙阻挡移动、视线和隔墙攻击。未知的墙后房间完全遮住，通过开放门口只显露真实可见部分；已探索但当前不可见的地形保留暗色记忆，怪物、血条和特效不会透过迷雾。普通攻击、超级技能和天雷都可攻击屏内且视线畅通的休眠守卫与首领，在各自射程内命中后唤醒，无需先踏入房间。索敌查询本身不唤醒敌人。墙体与人物只进行一次按脚底顺序的合成；已发现墙段独立平滑明暗，遮住人物的墙体按位置逐渐淡化，避免整面墙透明度突变及重复叠画。静止或暂停时不推进明暗动画，怪物可见性与伤害仍使用严格视线。墙面交点预计算并纳入视野射线，避免斜切当前房间内角；墙面、圆端底座与实体占地对齐，消除墙根黑缝。室内墙体不再套用室外倒木的投影。主角靠墙时由墙体前后排序处理遮挡，不受地面视野裁剪截掉头部；墙后的怪物和特效仍严格隐藏。

- 可从入口提前撤离，重返同一城堡保留探索、守卫生命和宝箱状态，不重新刷怪或奖励。
- 清理支路宝箱所在房间的守卫后才能开箱；击败最终首领后需靠近王城宝藏，选择城堡超级技能并领取资源，奖励选完后不会立即弹出；离开宝藏接触范围再碰一次可返回荒野，也可从原入口撤离。
- 城堡与小屋室内暂停外部怪潮和荒野目标的模拟；技能冷却、临时增益与伙伴助战时间照常流逝，返回不返还已消耗时间。
- 进出城堡与区域往返保留角色成长、技能、遗物与同行伙伴。区域分别保存建筑、传送门、专属守卫生命、未完成遗迹、迷宫探索和领奖状态；不会重复刷取首领与遗迹奖励。离开的区域暂停模拟，普通追击怪及临时弹体、回震、攻击预警会清理；切换提供约 2 秒落点保护。

**超级技能只能由对应首领奖励解锁，全部自动索敌、独立冷却。** 区域首领击败后立即选择；城堡仍需领取王城宝藏。普通灵晶强化不能获得未解锁的超级技能；获得后会加入灵晶强化池，最高 3 级。本局持有，跨区域、城堡保留。

| 来源 | 超级技能 | 特点 |
|---|---|---|
| 区域首领 | 荆棘缚阵 | 敌群脚下范围攻击，短暂定身普通敌人 |
| 区域首领 | 瘴雾侵蚀 | 持续侵蚀雾，周期造成范围伤害 |
| 区域首领 | 符文穿击 | 三道贯穿射线，同次攻击不重复命中 |
| 城堡最终首领 | 星陨 | 标记敌群位置，蓄能后造成高额范围伤害 |
| 城堡最终首领 | 王庭剑阵 | 连续灵剑，优先攻击首领和强敌 |
| 城堡最终首领 | 虚空漩涡 | 牵引普通敌人并持续伤害，不牵引首领 |

区域与城堡使用不同的三项技能池，区域奖励将当前区域特色技能排在前面。已解锁技能可由后续同类宝藏继续升阶；对应池全部满阶后改为资源奖励：区域额外 60 金币、100 灵晶，城堡额外 120 金币、180 灵晶，避免空面板。

六种超级技能强化了施法与命中表现，保持自动施放和原有冷却。一级荆棘伤害 84、半径 105、定身 1.25 秒；瘴雾先爆发 32 伤害，再每半秒造成 24 伤害、持续 4 秒；符文单次伤害 96；星陨每颗伤害 145、爆炸半径 86；王庭剑阵每剑 124 伤害，先短暂召剑再逐柄命中；漩涡每跳 27 伤害、牵引速度 82。各等级完整施法伤害较原版提高约 29%–40%。地图障碍、可见目标、技能射程与命中唤醒规则仍然生效。起爆、光束核心、落石裂痕和剑阵强化局部反馈，持续雾层保持透明；星陨音效与轻微震屏以实际落地为准并限制频率，减少动态效果模式关闭震屏。

右上角常驻小地图为方形（常规 128、窄或矮屏 104），不再常驻标题和文字图例；暂停按钮置于地图左侧，击杀数与计时合并为小统计。荒野、城堡与小屋共用世界地图的图标、玩家居中方式和 900 范围比例，点击地图或按 M 暂停并展开：显示已发现地标的名称、状态、距离与图例，室内额外叠加已探索的粗墙线，保留门口缺口，不绘制另一套房间网格。关闭地图恢复原有暂停或选择面板，不消耗灵晶、不自动做选择，不提前发现建筑。

## 环境、敌人和视觉

- 大树树干、巨石、倒木与建筑阻挡人物，敌人会绕行；野猪锁定方向后冲锋，撞障碍会短暂眩晕。孢子怪保持距离蓄力发射慢弹。
- 沼泽水潭会遮住地面单位的身体下部，深处下沉更明显，水线与涟漪随脚底移动；主角、地面怪物与伙伴移速降至 74%。飞行单位不下沉、不受水潭或藤蔓减速；飞行怪物仍会受到毒雾伤害。爆炸蘑菇被武器击中后预警 0.9 秒再爆炸，可伤害敌我并延迟引爆附近蘑菇；机关本身不产资源。
- 森林藤蔓预警后缠绕地面单位，可攻击切断；沼泽毒雾预警后短暂喷发。遗迹符文阵改为固定祭坛，触碰石台激活，每处仅一次。危险机关避开出生点、建筑与任务目标。
- 45 秒后少量普通怪可获得护盾、迅捷或召唤能力。特殊精英同时最多 3 只，仆从同时最多 6 只，并共用怪物总数上限。领主轮换震地与扇形孢子弹、固定孢爆，攻击有提前预警。
- 世界光束、光斑与萤火光点固定在地图坐标上。萤火在固定位置附近小幅飘动，随镜头平移而移动，缩放视口不会重排；暂停时停止，减少动态设置下保持静止。人物共用方向协调的地面投影，阴影合并后统一透明绘制，重叠不累积变黑；阳光在人物、地形与建筑的阴影区域被遮除，不再与阴影混色。人物和地形按脚底位置排序，树冠与屋顶适当淡化。
- 主动天雷至少生成 8 道蓝白主雷，少怪时补足屏内空击；分散怪群增加主雷，45 范围内的密集怪群共享主雷与短电弧。窄屏最多 24 道主雷、宽屏最多 32 道，超过上限的目标仍有局部雷击与命中反馈。雷击在 0.168 秒内分批落下，伤害始终在施放时对屏内每个有效目标独立结算一次；空击与分叉不重复造成伤害。全部落点使用施放时的世界坐标快照，暂停后静止，支持减少动态表现。战斗区域阻止文字选中和拖拽干扰。

## 版本号

开始画面的版本为 `v0.0.N`，`N` 是 GitHub 仓库 `goodleap/wild-reaper` 当前提交可达的历史提交总数，首次提交为 `v0.0.1`。GitHub Pages 在每次 `main` 推送后拉取完整历史并运行 `npm run stamp-version`，直接更新部署产物，不产生额外版本提交；仅修改文档的提交也计入。

Sites 使用独立源码仓库。同步发布前核对 GitHub `main` 的完整提交数，将本次改动计入，再运行 `npm run stamp-version -- --commit-count N`，使 Sites 和 GitHub Pages 版本一致。请勿使用 Sites 自身的 Git 计数。版本仅增加最后一段，`v0.0.9` 之后是 `v0.0.10`。
