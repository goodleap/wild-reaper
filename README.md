# 荒野回响 · Wild Echoes

纯 HTML、CSS 与原生 JavaScript Canvas 实现的无尽割草生存游戏，无运行时第三方依赖。所有人物、建筑、地形与特效均由代码绘制。

## 操作与基础玩法

- 自动瞄准、自动攻击；WASD / 方向键移动，空格释放主动技能「天雷轰击」，E 与附近目标互动，Esc / P 暂停。
- 手机拖动战斗区域使用虚拟摇杆，通过屏幕按钮释放主动技能、进入传送门、交易或探索建筑。
- 开局固定使用旅人：米白软兜帽、绿色披风、空手，速度 220、生命 100（轻松模式 140），初始仅有翠羽飞矢。标准 / 轻松难度使用单选按钮，保存本机纪录和难度偏好，可关闭合成音效。
- 没有时长上限；荒野怪潮随时间升级，穿插短促围攻与缓和。首位区域领主在 02:00 出现，之后约每 150 秒迎来更强的领主，同时最多一位区域领主存活；区域宝藏尚未通过传送门领取时，下一位领主也会等待。

链接添加 `?debug`、`?debug=1` 或 `?debug=true` 可进入调试模式，开始页版本旁显示 DEBUG。首区域的城堡入口会放在出生点附近，便于走过去测试进出、迷宫和宝藏；普通模式按正常探索距离生成。每局开场一次性获得 500 金币和 150 灵晶，灵晶按正常规则提供两次技能强化选择；进出城堡或切换区域不会再次发放。角色等级和战斗规则保持正常，后续区域仍使用正常布局；去掉参数或设为 `debug=0` 即可关闭。

## 战斗节奏

开场先探索与收集灵晶，约 20 秒后预警第一波定向怪潮。3 秒方向提示后，从同一侧投放有限怪群；推进、蝙蝠掠袭与冲锋夹击轮换，野猪和孢子仍受出场时间与数量限制。界面显示剩余怪数。清完后获得少量灵晶，并吸引附近战利品；随后 8 秒停止新刷怪，再留出探索时间。拖得过久会进入较短缓和期，没有清潮奖励。怪物总数仍受上限约束，后期也保留明确的缓和阶段。

忽略远处营救、离开小屋战斗、保留传送门，都不会无限期压住其他事件。附近正在进行的可选战斗仍会避让；真实首领临近和首领战期间避免同时开启新挑战。

城堡保留 5×5 连通迷宫与支路宝箱，首领主线缩短至约 8 个房间距离。主线战斗房集中安排 4–6 个守卫，清房提供少量灵晶，部分房间有药草；小地图标出通往下一目标的房间。撤退保留守卫、清房和宝箱状态，不能重复刷取奖励。

## 画面与战斗表现

森林地表使用固定世界坐标的草叶、落叶、苔藓与泥土纹理；沼泽增加湿土、水洼、芦苇与枯木，遗迹增加磨损石板、碎石和断柱。城堡外观使用有厚度的石墙、拱门与塔楼，迷宫内使用铺石地面和立体墙体。树皮、岩面、倒木、小屋和这些区域素材都在首次使用时绘制为离屏位图并复用。小屋保持略大于主角的比例，旅人的原有形象、地形碰撞和日光／阴影遮挡规则沿用现有实现。

林间狩猎以圆形石铺擂台标记有效战斗范围，加入磨损石沿、苔藓、中央纹章、入口踏步与四座矮火盆。击杀进度逐步点亮边缘刻石；矮火盆与人物按脚底排序，并沿用合并阴影。擂台优先选在无遮挡的地面，既有地形危险仍显示在石台上方。

全部六类小怪和两类首领增加材质、明暗和轮廓细节：史莱姆的湿润表面、蝙蝠翼膜、甲虫背甲、蘑菇菌褶、野猪鬃毛，以及古树领主的树皮／枝角和孢冠领主的层叠菌盖。有限数量的姿态与受击帧共用缓存。补给木箱、普通宝箱、王城宝藏、传送门、拾取道具、敌方弹体与环刃也使用更完整的造型。

飞矢拥有箭镞、尾羽与渐细拖尾；连锁雷电具备分叉电弧、明亮核心与命中电花；地震呈现裂隙、石块和扬尘，主角与伙伴共用同一表现。怪物受击时短暂压缩、后仰，死亡时碎散消退；这些变化只影响画面，不改变攻击伤害、目标、冷却或奖励。

六种超级技能各有独立表现：荆棘生长、侵蚀雾团、带符文的能量射线、星陨的蓄能标记与坠落冲击、王庭灵剑，以及带卷吸碎屑的虚空漩涡。星陨在伤害触发前下降，命中后呈现焦痕和碎石；攻击原点、范围、伤害时刻与数值沿用现有规则。

素材均由项目代码生成，没有外部图片请求或新增运行依赖。森林、区域、怪物、超级技能和道具位图分别采用 12、10、6、4、3 MiB 的缓存上限，并按需要创建素材。特效几何按对象缓存，时间来自战斗模拟，暂停时保持静止。普通特效总量上限 200，死亡效果上限 24；窄屏或密集战斗减少分叉与碎片，减少动态效果模式禁用拖尾运动、碎片飞散和镜头震动。攻击范围提示与敌人预警保持可见。

## 三种成长资源

| 资源 | 获得方式 | 用途 |
|---|---|---|
| 经验 | 击杀有经验的敌人后自动获得，无需拾取 | 自动提升角色等级；每级增加 2 点最大生命，并恢复相应的 2 点生命，基础伤害倍率增加 1 个百分点 |
| 灵晶 | 击杀非首领敌人掉落，靠近吸收；也可由探索奖励直接获得 | 独立累积至门槛后，暂停并从三项技能或被动强化中选择一项 |
| 金币 | 普通敌人有 8% 概率掉落 1 枚；特殊精英保底掉落 3 枚；探索奖励也可获得 | 向商人购买补给与遗物 |

角色升级不弹出选择面板，不提高移速或攻速，也不限制技能槽位。第一次灵晶强化固定在环刃、大地回响、唤雷中选择一种，选定后立即投入自动攻击；后续恢复常规强化池，灵晶费用保持不变。角色经验、灵晶强化进度与金币分别显示；灵晶和金币沿用靠近吸附，基础拾取范围 105。

灵晶强化需求随独立的强化次数递增，多余灵晶保留；一次攻击完成后才打开强化面板，避免中断同一批伤害。升级选项在面板内保持稳定，连续强化可在同一面板完成。召唤仆从不提供经验、灵晶或金币。营救与占据屋的有限守卫提供少量击杀经验及对应灵晶，事件完成本身不额外赠送角色经验。

## 常规技能与分支

| 技能 | 效果 | 进化或分支 |
|---|---|---|
| 翠羽飞矢 | 自动瞄准可见敌人，基础伤害 32 | 飞矢等级达到 4 后选择穿林飞矢或弹射飞矢；等级为 `1 + 疾风连射等级 + 分裂箭等级` |
| 环刃 | 绕身攻击，施加流血 | 5 级自动进化为周期扩张、收拢的裂风环刃 |
| 大地回响 | 环形震波、击退敌人 | 从 4 级升至 5 级时，选择连续震波或撼地重震 |
| 唤雷 | 自动连锁闪电，附加感电 | 从 4 级升至 5 级时，选择雷暴链或聚雷轰击 |
| 天雷轰击 | 手动释放，攻击当前屏幕内的敌人，基础冷却 15 秒 | 暂无分支 |

- 穿林飞矢最多穿透三个不同目标；弹射飞矢在附近可见敌人间最多跳转两次，每次后续命中保留上一段 65% 伤害。分裂箭保留全伤主箭，副箭造成 60% 伤害。
- 连续震波在施法原位置追加 60% 伤害的扩大回波；撼地重震扩大范围、增强击退并短暂减速普通敌人。雷暴链攻击最多五个目标，最后两段伤害降低；聚雷轰击集中攻击一个目标，优先首领与高生命敌人。
- 分支面板提供同一武器的两条路线和一项普通强化，可选普通强化暂缓。分支消耗一次灵晶强化机会，选定后本局固定，跨区域与城堡保留。
- 环刃施加持续 2 秒的流血，重复命中刷新时长、不叠层；地震与回震消耗流血，使该次伤害增加 25%。雷电与天雷施加 2.5 秒感电，下次飞矢或环刃命中时向附近另一名敌人传导一次。流血与传导不会递归触发联动。
- 被动强化包括锋芒、疾风连射、分裂箭、轻盈步伐、林间引力、古树之心与生生不息；后期仍有无尽强化选项。

## 伙伴与地图 NPC

击败营地的六名守卫，再靠近受困者即可解救唤雷者或守林人。每次解救使「援助之力」增加一级，即基础伤害倍率增加 8 个百分点；奖励仅一次，本局持续有效。伙伴跟随助战 60 秒，不承受伤害、不挡路。营救会避开活跃领主、限时事件与正在挑战的小屋。

伙伴使用主角被动技能的高级版本，独立施法、独立冷却：唤雷者从自身位置发出最多五目标的连锁闪电，使用同样的闪电表现并附加感电；守林人从脚下发出地震和原位回震，可消耗流血。伙伴不使用主角的主动天雷表现。

两位伙伴与旅人的身高、身宽相近，靠服装、配色和装备细节区分。三者共用按实际位移推进的迈步与起伏，站定或被障碍挡住时停止迈步；跟随有起步与减速，减少原地微调。商人与天使也保持相近的人物比例。

- **商人**：独立站在荒野中的游商，与小屋分开生成，没有房屋或建筑碰撞。主动交易期间暂停战斗；成功购买一件商品后游商离开，交易面板关闭，本区域不再出现。仅查看、取消或购买失败时仍会留下。药剂 12 金币，恢复 35 点生命；磁引符与狂暴药剂各 8 金币；守护符 16 金币，可抵消下一次受击的至多 18 点伤害；一件固定的轮换遗物 60 金币。每样库存一份，金币不足、满血买药、已拥有遗物或护盾已充盈时不扣费。
- **天使**：每处提供一次祝福，恢复 35% 最大生命；满血时改为一次 18 点伤害吸收。生命与护盾均充盈时保留祝福，可稍后使用。
- **小屋**：屋身略高于主角，屋檐宽约 66–70，地基宽 54–58、深 28–30；碰撞与阴影同步缩小。普通小屋提供少量资源与药草；被占据的小屋可主动挑战四名守卫，清理后返回门口领取更好的宝藏。

每个区域最多五处固定目标：游商、补给屋、占据屋、天使圣坛与城堡入口。建筑有脚底碰撞与前后遮挡，屋顶遮住人物时淡化；入口留有通行空间，与危险机关和其他目标分开。已领取奖励不会因离开视野而刷新。

## 区域、城堡与超级技能

区域按低语之森 → 迷雾沼泽 → 失落遗迹循环。击败区域首领后出现传送门；靠近按 E 或点击进入，选择区域超级技能后切图，走过不会自动传送。存在活跃区域首领时暂不能进入城堡或旧传送门。

城堡入口通向独立的 **5 × 5 有限迷宫**，含宽走廊、已探索区域小地图、有限守卫、三个支路宝箱与最终首领。迷宫由固定种子生成并保持连通，最终首领位于距入口最远的房间之一；城墙阻挡移动和隔墙攻击，未激活房间的守卫不会被远程清空。

- 可从入口提前撤离，重返同一城堡保留探索、守卫生命和宝箱状态，不重新刷怪或奖励。
- 清理支路宝箱所在房间的守卫后才能开箱；击败最终首领后需靠近王城宝藏，选择城堡超级技能并领取资源，再从宝藏处直接返回荒野。
- 城堡内暂停外部怪潮、区域首领日程与未救营地计时；技能冷却、临时增益与伙伴助战时间照常流逝，返回不返还已消耗时间。
- 进出城堡保留角色、灵晶、金币、技能、遗物、伙伴与原荒野场景；切换区域则清除旧区未完成目标和未拾取物。场景切换清理弹体、回震及攻击预警，并提供约 2 秒落点保护。

**超级技能只能由对应首领宝藏解锁，全部自动索敌、独立冷却。** 普通灵晶强化不能获得未解锁的超级技能；获得后会加入灵晶强化池，最高 3 级。本局持有，跨区域、城堡保留。

| 来源 | 超级技能 | 特点 |
|---|---|---|
| 区域首领 | 荆棘缚阵 | 敌群脚下范围攻击，短暂定身普通敌人 |
| 区域首领 | 瘴雾侵蚀 | 持续侵蚀雾，周期造成范围伤害 |
| 区域首领 | 符文穿击 | 三道贯穿射线，同次攻击不重复命中 |
| 城堡最终首领 | 星陨 | 标记敌群位置，蓄能后造成高额范围伤害 |
| 城堡最终首领 | 王庭剑阵 | 连续灵剑，优先攻击首领和强敌 |
| 城堡最终首领 | 虚空漩涡 | 牵引普通敌人并持续伤害，不牵引首领 |

区域与城堡使用不同的三项技能池，区域奖励将当前区域特色技能排在前面。已解锁技能可由后续同类宝藏继续升阶；对应池全部满阶后改为资源奖励：区域额外 60 金币、100 灵晶，城堡额外 120 金币、180 灵晶，避免空面板。

## 奖励分层

下表列出各类目标的主要收益。宝箱和事件奖励独立于沿途击杀收益，每个具体宝箱或事件仅领取一次。

| 来源 | 奖励定位与内容 |
|---|---|
| 补给木箱 | 药草、磁铁、狂暴之一 |
| 普通小屋 | 4 金币、12 灵晶、药草 |
| 特殊精英怪 | 更多击杀经验与灵晶，保底 3 金币 |
| 宝物精追逐 | 24 金币、8 灵晶、磁铁，以金币为主 |
| 限时狩猎 | 6 金币、40 灵晶、狂暴，以技能成长为主 |
| 精英守卫宝箱 | 18 金币、35 灵晶，药草、磁铁、狂暴各一份 |
| 被占据的小屋 | 24 金币、40 灵晶，药草与狂暴 |
| 城堡支路宝箱 | 12 金币、24 灵晶、药草 |
| 区域首领 | 30 金币、45 灵晶，传送门领取一项区域超级技能 |
| 城堡最终宝藏 | 80 金币、100 灵晶，保底选择一项城堡超级技能 |
| 营救 NPC | 60 秒伙伴助战，援助之力增加一级 |
| 天使 / 遗迹符文阵 | 一次恢复或护盾 / 12 秒临时助攻 |

药草基础恢复 25 点生命，满血时也会拾取并消耗，生命值不会超出上限；没有实际治疗时不触发春芽符。磁铁扩大灵晶与金币吸附范围；狂暴提高 35% 伤害与 20% 飞矢发射频率，两种增益默认持续 8 秒，重复拾取刷新时长。

原有六种遗物通过商人获得，每局各持有一份：引雷石缩短主动技能冷却并设每秒上限；赤心在低生命时增伤；春芽符让药草触发冲击波；铁叶护符周期恢复伤害吸收；风羽提高移速；深根提高药草治疗。遗物与超级技能相互独立。

## 环境、敌人和视觉

- 大树树干、巨石、倒木与建筑阻挡人物，敌人会绕行；野猪锁定方向后冲锋，撞障碍会短暂眩晕。孢子怪保持距离蓄力发射慢弹。
- 泥地使敌我主动移速降至 74%；爆炸蘑菇被武器击中后预警 0.9 秒再爆炸，可伤害敌我并延迟引爆附近蘑菇。机关本身不产资源，击杀有经验的敌人仍按普通规则结算。
- 森林藤蔓预警后缠绕减速，可攻击切断；沼泽毒雾预警后短暂喷发；遗迹符文阵踏入蓄能后助攻，每处只激活一次。危险机关避开出生点、建筑与任务目标。
- 45 秒后少量普通怪可获得护盾、迅捷或召唤能力。特殊精英同时最多 3 只，仆从同时最多 6 只，并共用怪物总数上限。领主轮换震地与扇形孢子弹、固定孢爆，攻击有提前预警。
- 世界光束、光斑与萤火光点固定在地图坐标上。萤火在固定位置附近小幅飘动，随镜头平移而移动，缩放视口不会重排；暂停时停止，减少动态设置下保持静止。人物共用方向协调的地面投影，阴影合并后统一透明绘制，重叠不累积变黑；阳光在人物、地形与建筑的阴影区域被遮除，不再与阴影混色。人物和地形按脚底位置排序，树冠与屋顶适当淡化。
- 主动天雷使用蓝白分叉闪电、回闪与落点电弧；密集怪群限制详细主雷数量，仍保留命中反馈。支持减少动态表现，阻止战斗区域文字选中和拖拽干扰。

## 文件与部署

- `dist/index.html` / `dist/style.css`：页面、状态栏、商店、强化与奖励面板、响应式布局。
- `dist/app.js`：Canvas 绘制、输入、音效、建筑与迷宫界面。
- `dist/engine.js` / `dist/weapon-branches.js`：战斗、独立成长资源、技能选择及分支。
- `dist/wave-director.js` / `dist/event-scheduling.js`：有限定向怪潮、清潮回报和可选目标避让。
- `dist/super-skills.js`：六种超级技能、首领奖励池、自动施法和数量边界。
- `dist/scenery-art.js` / `dist/combat-art.js`：缓存的场景素材和按模拟时间播放的战斗特效。
- `dist/settlements.js` / `dist/dungeon.js`：建筑 NPC、商店、小屋挑战，以及独立有限城堡的探索和场景往返。
- `dist/terrain.js`：程序地形、建筑独立碰撞层、城墙、移动碰撞与绕行几何。
- `dist/adventure.js` / `dist/encounters.js`：守卫宝箱、木箱、即时道具、追逐与狩猎奖励。
- `dist/encounter-art.js`：林间狩猎圆形石擂台、进度刻石和矮火盆，位图缓存上限 4 MiB。
- `dist/heroes.js` / `dist/companions.js` / `dist/locomotion.js`：固定主角、营救与助战、共用行走状态。
- `dist/combat-status.js` / `dist/relics.js`：流血、感电、遗物与一次性护盾。
- `dist/environment.js` / `dist/regional-mechanisms.js`：泥地、蘑菇、藤蔓、毒雾与符文阵。
- `dist/regions.js` / `dist/bosses.js` / `dist/elites.js`：区域、传送门、领主攻击与特殊精英。

将 `dist` 作为静态网站目录即可部署，所有资源均使用相对路径。

## 版本号

开始画面的版本为 `v0.0.N`，`N` 是 GitHub 仓库 `goodleap/wild-reaper` 当前提交可达的历史提交总数，首次提交为 `v0.0.1`。GitHub Pages 在每次 `main` 推送后拉取完整历史并运行 `npm run stamp-version`，直接更新部署产物，不产生额外版本提交；仅修改文档的提交也计入。

Sites 使用独立源码仓库。同步发布前核对 GitHub `main` 的完整提交数，将本次改动计入，再运行 `npm run stamp-version -- --commit-count N`，使 Sites 和 GitHub Pages 版本一致。请勿使用 Sites 自身的 Git 计数。版本仅增加最后一段，`v0.0.9` 之后是 `v0.0.10`。
