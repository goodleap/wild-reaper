# 荒野回响 · Wild Echoes

纯 HTML、CSS 与原生 JavaScript Canvas 实现的无尽割草生存游戏，无运行时第三方依赖。

- 自动瞄准与发射；WASD / 方向键移动，空格释放天雷轰击，Esc / P 暂停。
- 手机拖动战斗区域使用虚拟摇杆，右下角按钮释放天雷轰击。
- 拾取灵晶获得经验，每次升级从三个随机强化中选择一个。
- 环绕飞刃、范围冲击波、连锁闪电与多项被动强化。
- 主动技能天雷轰击：伤害覆盖释放时屏幕内的全部怪物，冷却 15 秒，伤害随强化提升。
- 森林光束与光斑固定在地图坐标上，随镜头移动，不跟随角色。
- 主角、小怪与领主共用朝向一致的地面投影；阴影合并后统一透明绘制，重叠不累积变黑，角色按脚底位置排列前后遮挡。
- 没有时长上限；每分钟提升怪潮强度，首位领主 02:30 出现，之后约每 150 秒迎来更强的领主。
- 同时最多一位领主存活，未击败时下一位会等待；后期升级仍可继续强化。
- 标准 / 轻松难度通过单选按钮切换，无尽模式本机纪录与可关闭的合成音效。

## 文件

- `dist/index.html`：页面、状态面板与弹窗。
- `dist/style.css`：桌面、手机竖屏与横屏布局。
- `dist/app.js`：Canvas 绘制、输入、音效与界面同步。
- `dist/engine.js`：独立战斗与升级逻辑。

将 `dist` 作为静态网站目录即可部署，所有资源均使用相对路径。

## 验证

运行 `npm run check` 检查语法，`npm test` 运行整局模拟以及暂停升级、全屏雷击及冷却、死亡和无尽进阶检查。

已运行引擎模拟和 Canvas 离线绘制检查，包括阴影重叠不加深、脚底排序、密集怪群、DPR 与屏幕旋转；未进行真实浏览器与真实触屏设备测试。
